# Week 1 — Cyber Threat Intelligence Fundamentals

## 1. Introduction

Cyber Threat Intelligence (CTI) is information about existing or potential cyber threats that can help organizations understand attacker behavior and improve security decisions.

In this project, CTI methods are applied to phishing infrastructure. The focus is on identifying and analyzing phishing-related indicators such as malicious URLs, domains, and IP addresses.

## 2. Key CTI Terms

| Term | Definition |
|---|---|
| Cyber Threat Intelligence (CTI) | Information about cyber threats that can support security decisions. |
| Indicator of Compromise (IOC) | Evidence that may indicate malicious activity, such as an IP address, domain, URL, or file hash. |
| Threat Actor | An individual or group responsible for malicious cyber activity. |
| TTP | Tactics, Techniques, and Procedures used by threat actors. |
| OSINT | Intelligence collected from publicly available sources. |
| Phishing | A social engineering technique used to steal credentials or deliver malicious content. |
| Malicious Domain | A domain used for phishing, malware delivery, or other malicious activity. |
| Threat Feed | A source that provides information about malicious indicators and cyber threats. |
| Data Enrichment | Adding additional information and context to an existing indicator. |
| MISP | An open-source platform used to collect, store, share, and analyze threat intelligence. |

## 3. Phishing Threat Classification

The main threat analyzed in this project is phishing.

Common phishing-related threats include:

- Credential phishing
- Spear phishing
- Business Email Compromise
- Malware delivery through phishing
- Fake login pages
- Typosquatting domains
- QR phishing

## 4. Threat Intelligence Sources

Several public sources can be used to investigate phishing infrastructure:

| Source | Purpose |
|---|---|
| VirusTotal | Analysis of URLs, domains, IP addresses, and files |
| URLhaus | Information about malicious URLs |
| PhishTank | Community-based phishing URL database |
| AlienVault OTX | Threat intelligence indicators and pulses |
| AbuseIPDB | IP reputation analysis |
| WHOIS | Domain registration information |
| crt.sh | Certificate Transparency search |
| MISP | Threat intelligence storage and correlation |

## 5. Relevance to the Project

The CTI concepts studied during Week 1 provide the theoretical foundation for analyzing phishing infrastructure.

In the following weeks, these concepts will be used to collect phishing indicators from open sources, process the data, and identify relationships between malicious URLs, domains, and IP addresses.
